# 津门社区养老数据观察（天津版）

> 这是一个**独立文件夹**：网站、数据、脚本、图表、文档都在本目录内，不依赖根目录的上海版。

## 一、打开网站

- 双击 `index.html`（离线可用）；
- 或双击本文件夹的 `启动网站.bat`。

## 二、页面结构

1. **首页**：16 区、300.27 万 60+ 老人（2020 七普）、2,015 个助餐点、1,342 个日间照料中心。
2. **数据图表**：4 个标签切换——人口、设施（热力图）、占比（助餐/日照点位构成）、匹配（老龄化 × 日照密度）。
3. **设施账单**：16 区卡片，按便利指数/老龄化/日照/助餐排序，可搜索区名，附官方名单链接。
4. **资源优先级实验室**：拖动助餐/日照/卫生床位三项权重，实时重算 16 区便利指数和排名，附“最均衡/最需要补”的结论。
5. **分析结论**：河北老龄化 31.0%、河西助餐 1.7 个/万、和平综合指数 67.1 等。

## 四、重新生成

在本文件夹内运行：

```bash
pip install pandas matplotlib adjustText
python src/06_tianjin_analysis.py
python src/07_build_web_tj.py
```

- 修改 `data/selected/天津各区_2020人口_2025设施.csv` 后，重跑这两个脚本即可；
- `06` 输出图、表、摘要；`07` 只更新 `data/app_data.js`。

## 五、数据口径

- 人口：2020 年第七次全国人口普查；
- 助餐/日照：天津市民政局 2025 年区级名单逐行统计；
- 卫生床位：2024 年天津统计年鉴；
- 完整口径与局限见 `docs/天津数据说明.md`。

## 六、发布到 GitHub Pages

不需要安装 git。准备一个带 `repo` 权限的 GitHub Token，然后双击：

```text
发布到GitHub.bat
```

按提示粘贴 Token，脚本会自动创建仓库、上传文件、开启 Pages，并输出网址。

详细步骤见 `如何发布到GitHub.md`；也可以手动上传 `github-pages.zip`。
