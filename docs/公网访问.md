# 公网访问说明

## 当前临时地址（天津版）

https://extend-quiet-appropriate-complicated.trycloudflare.com

- 由 Cloudflare Quick Tunnel 提供，任何浏览器可直接打开；
- **电脑不能关机/休眠**，本地静态服务器和隧道进程要保持运行；
- 隧道重启后地址会变化，答辩前请重新生成并替换本文件。

## 重新启动（本机）

```bash
# 1. 启动天津版静态服务器（在项目根目录）
python -m http.server 8765 --bind 127.0.0.1 --directory 天津版

# 2. 另开一个终端，启动公网隧道
cloudflared tunnel --url http://127.0.0.1:8765 --no-autoupdate
```

终端会输出一个 `https://xxxx.trycloudflare.com` 地址，复制到浏览器即可。

## 固定网址（推荐答辩前做）

临时隧道适合演示，不适合长期使用。要一个不会变的网址，任选一种：

1. **Netlify Drop**：打开 https://app.netlify.com/drop ，把本文件夹的 `github-pages.zip` 解压后，把里面的文件整体拖进去；登录后可保留站点并改域名。
2. **GitHub Pages**：新建仓库，上传 `github-pages.zip` 解压后的文件到仓库根目录，Settings → Pages → 选择分支，得到 `https://用户名.github.io/仓库名/`。
3. **Cloudflare Pages**：登录 Cloudflare，创建 Pages 项目，上传解压后的文件。

三种方式都只需要静态文件，不需要后端和数据库；`data/app_data.js` 和 `vendor/echarts.min.js` 要一起上传。

> 详细步骤见 `docs/部署到GitHub Pages.md`。天津版部署包是本文件夹的 `github-pages.zip`；项目根目录的 `github-pages.zip` 是上海版备档。
