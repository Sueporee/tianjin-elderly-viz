# 天津版答辩讲稿（约 3 分钟）

> 配合天津版文件夹的 `index.html` 和 `outputs/figures/天津_图1~3.png`。数字与 `outputs/天津数据分析摘要.md` 一致。

## 一、开场（15 秒）

我们组的题目是《社区老年人常用便民服务大数据可视化分析》，这一版用的是**天津本地公开数据**：16 个区、2020 年七普老年人口，加上 2024—2025 年助餐点、日间照料中心和卫生床位。除了三张图，我们还做了一个可交互的展示网站。

## 二、数据与清洗（40 秒）

数据分三块：

- 老年人口：天津市第七次全国人口普查，16 区 60 岁以上共 300.27 万，老龄化率 21.7%；
- 助餐点：民政局“老人家食堂”区级名单，15 个区有图片名单，我们逐行统计；蓟州没有公开图片，按周边涉农区均值估算；
- 日间照料中心：16 个区的 PDF 清单，用表格行线检测逐行统计；
- 卫生床位：2025 天津统计年鉴表 22-14，各区合计 73,216 张，和年鉴完全对上。

需要说明的是，人口是 2020 年、设施是 2025 年，这是一次**结构对照**，不是同一年快照；助餐和日照名单有的区包含村居级点位，横向比较要谨慎。

## 三、三张图（65 秒）

**图 1**：河北区老龄化最高，31.0%；红桥 30.7%、河东 28.8%；津南最低 15.9%。天津的老龄化压力明显集中在海河沿线老城区。

**图 2**：每万老人设施配置和综合便利指数。和平最高 67.1，河西最低 14.7。河西每万老人只有 1.7 个助餐点，和平是 9.8 个；南开每万老人只有 0.4 个日间照料中心，静海有 21.8 个，但静海很多是村居级点位，口径要说明。

**图 3**：老龄化率和每万老人日照中心，相关系数 r = -0.35。高老龄化区并没有更多日照，河北、红桥、河东都落在“高老龄化、低日照”这一侧。

## 四、网站与实验室（35 秒）

网站是纯静态页面，双击 `index.html` 就能打开。上面四张图可以点击切换、悬浮看数值；设施账单按区展示三笔账，可以搜索区名。

最有意思的是页面底部的**“资源优先级实验室”**：拖动助餐、日照、卫生床位三条权重滑块，16 区的便利指数排名会实时变化；还可以一键切换“吃饭优先 / 照护优先 / 就医优先”。它想说明的是：资源有限时，不存在唯一正确的排名，只有社区自己的优先级。

## 五、结论与局限（25 秒）

我们的建议是：河北、红桥、河东优先补日照；河西、南开先核对助餐名单完整性再补点；三类设施联合选址，避免重复建设。

局限也要主动说：人口是 2020 年、设施是 2025 年；助餐/日照名单口径不完全统一；蓟州助餐是估算；卫生床位不是养老床位。这些在 `docs/天津数据说明.md` 里都写了。

## 附：老师可能追问

**Q1：为什么用 2020 年人口？**
A：天津统计年鉴没有 2024 年分区 60+ 的完整口径，七普是唯一能拿到 16 区 60+ 人口的公开数据；设施用 2024—2025 年，做结构对照，并在文档里明确时间错位。

**Q2：助餐点 2,015 和官方 1,852 为什么不一样？**
A：官方 1,852 是全市“老人家食堂”口径；我们的 2,015 是区级名单逐行统计，含蓟州约 90 个估算，部分区名单可能包含不同级别点位，所以有差异，文档里已说明。

**Q3：综合便利指数怎么算？**
A：助餐点、日间照料、卫生床位三项，各自按每万老人拥有量做 min-max 归一化，再按 0.40、0.35、0.25 加权。网站底部可以自己改权重。

**Q4：为什么河西助餐这么低？**
A：按公开名单逐行统计，河西每万老人 1.7 个，和平 9.8 个。这个差异可能来自名单完整性，不一定完全代表实际供给；我们在结论里建议先核对名单再补点。

**Q5：网站怎么做的？**
A：纯前端 HTML/CSS/JS + 本地 ECharts，无后端、无数据库；数据由 `07_build_web_tj.py` 生成 `data/app_data.js`，双击即可离线打开，也可以部署到 GitHub Pages。

**Q6：创新点是什么？**
A：一是把天津本地的助餐、日照、卫生床位放在同一张区级账本里；二是底部“资源优先级实验室”，让用户自己调权重、实时看排名变化，而不是只看一张固定结论图。
