# 点位数据补充说明

## 先说结论

**官方没有一份现成的“天津全市养老设施点位 CSV”可以直接下载。**  
民政局公开的是：

- 老人家食堂：区级图片名单（名称、地址、电话、供餐方式）；
- 日间照料中心：区级 PDF 名单（名称、地址、运营方、电话）；
- 养老机构：部分区图片/名单；
- 卫生机构：统计年鉴只有区级床位，没有点位。

所以 B 的“附近地图”有两条路：

1. **不补 CSV**：我从 `data/raw/` 里的图片/PDF 抽名称和地址，再做街道级近似坐标。中心城区试点够用，但精度到街道/道路，不到门牌。
2. **补 CSV**：你按下面的模板整理点位；如果能拿到高德/百度坐标，就能精确到小区/门牌。

## 需要补的 CSV 格式

文件：`data/selected/点位补充模板.csv`

| 列 | 必填 | 说明 |
|---|---|---|
| 名称 | 是 | 例如“劝业场街爱建公寓老人家食堂” |
| 类型 | 是 | `助餐点` / `日间照料` / `卫生服务` |
| 区 | 是 | 和平区、河西区…… |
| 街道 | 否 | 劝业场街道、小白楼街道…… |
| 地址 | 是 | 越完整越好，最好带门牌号 |
| 经度 | 精确坐标必填 | 例如 117.1909 |
| 纬度 | 精确坐标必填 | 例如 39.1199 |
| 坐标系 | 有坐标时必填 | `WGS84` 或 `GCJ-02`（高德是 GCJ-02） |
| 电话 | 否 | 民政局名单里的电话 |
| 来源 | 否 | 哪个区、哪份名单 |

> 如果只做街道级近似，`经度/纬度` 可以先空着，我来补。

## 官方名单在哪里下载

### 1. 老人家食堂（助餐点）

https://mz.tj.gov.cn/tjsmzjylc/gspd/stzcdt/

- 15 个区有图片名单（蓟州暂未发布）；
- 图片里包含：食堂名称、级别、详细地址、联系电话、三餐供应；
- 没有 CSV，需要另存图片或手动整理。

### 2. 社区老年人日间照料中心

https://mz.tj.gov.cn/tjsmzjylc/gspd/sqylfwss/202511/t20251128_7187922.html

- 16 个区 PDF；
- PDF 里包含：区、名称、地点、管理运营方、服务电话；
- 没有 CSV。

### 3. 养老机构名单

https://mz.tj.gov.cn/tjsmzjylc/gspd/yljgmd/

- 目前主要是滨海新区、市级国办等名单；
- 不是全市完整点位，做 B 时只能作补充。

### 4. 天津开放数据平台（可能有零散数据集）

https://open.data.tj.gov.cn/

搜索“养老”“养老机构”，能下到 XLS/CSV 的数据集多为：

- 某个区（如南开、河北、津南）自己的养老机构；
- 年份偏旧（2021—2023）；
- 字段不统一，且不一定有坐标。

可以作为补充，但不能当作全市完整点位。

### 5. 国家政务服务平台“全国养老机构信息查询”

http://app.gjzwfw.gov.cn/jmopen/webapp/html5/qgyljgxxcx/index.html

- 可查机构名称、地址、床位数；
- 没有批量 CSV 下载，查询还要验证码；
- 适合抽查，不适合全量整理。

## 精确坐标从哪里来

需要地图开放平台的 Geocoding/POI 接口：

- 高德开放平台：https://lbs.amap.com/api/webservice/guide/api/georegeo
- 百度地图开放平台：https://lbsyun.baidu.com/

两者都需要注册开发者、创建应用、拿到 key。  
有 key 后我可以批量把地址转成经纬度；没有 key 就只能：

- 用 OpenStreetMap/Photon 做街道级近似；
- 或者你手动在高德地图上点位置，填经度和纬度。

## 现在需要你做什么

如果接受“街道级近似 + 中心城区试点”：

- **你什么都不用下载**；
- 我用现有 `data/raw/` 的 5 个中心城区名单抽取；
- 坐标标注为“街道级近似”，不假装门牌精度。

如果你要“精确门牌”：

- 给我一个高德或百度地图 key；
- 或者按 `点位补充模板.csv` 填 5 个中心城区的点位和坐标。

不要从来源不明的“天津养老机构大全 CSV”下载：字段、年份、授权都不清楚，答辩时反而容易被问住。
